Manual Car Queue

Edit cars that could not be matched by the scraper. Once the tracked fields are filled, the car leaves the queue.

How to use this page

−
  1. This page lists cars with missing stats the scraper could not fill.
  2. Click Edit for a car, fill in the missing fields, and click Save Manual Update. The car leaves the queue once all tracked fields are populated.
  3. When finished, choose one export option:
    • Download merged data.js — generates a complete data.js with your edits. Save it over js/data.js in your repo.
    • Export manual cars JSON — downloads manual_cars.json. Merge it with python scripts/merge_manual_cars.py manual_cars.json.
  4. Run python scripts/validate_data.py after merging to check for errors.
