My Garage

Cars imported from your screenshots. This data is committed to the repository so it works on every device.

How to update

−
  1. Save car-detail screenshots to garage-screenshots/.
  2. Run python scripts/update_garage.py locally (requires Tesseract).
  3. Review the generated js/garage_data.js and commit it.
  4. Push to GitHub — the live site will use the updated garage.

Add a car manually

−

Use this form to add or update a car in your local garage. Manual entries are saved in this browser and overlay any imported data.
